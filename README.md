# Дзен пруд

Спокойный пруд, где живут аксолотли, тропические рыбки, лягушки и улитки.

- Нажми на воду, чтобы покормить жителей.
- «Украсить» — посадить кувшинки, розовые кусты, лягушек и улиток или убрать лишнее.
- 🌗 — день и ночь по часам, со светлячками ночью.

Пруд сохраняется в браузере. Весь сайт — один файл `index.html`.
